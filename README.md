# 🚩 こっきクイズ (FlagQuiz)

子どもがスマートフォンで楽しく遊べる国旗クイズWebアプリです。

## 🌟 主な機能
- **3つの出題形式 + ランダム**:
  - 🚩 **国旗あて**: 国旗を見て国名を4択から選択
  - 🔤 **なまえあて**: 国名を見て4つの国旗文字・画像から選択
  - 📖 **ゆらいクイズ**: 国旗のデザインや色の意味、星の数などの検定トリビア
  - 🎲 **ランダム**: すべての出題パターンがミックス
- **ちいき（エリア）フィルター**:
  - 全世界（120カ国対応）、アジア、ヨーロッパ、アフリカ、北・中央アメリカ、南アメリカ、オセアニア
- **もんだいすう**: 5問、10問、20問、50問、**100問**
- **制限時間**: **3秒（超スピード）**、5秒、10秒、15秒、なし（じっくり）
- **子ども向けUI**:
  - 漢字に「ふりがな（ルビ）」を標準表示（ON/OFF可能）
  - スマホで押しやすい大きなボタン
  - Web Audio APIによる軽快な効果音（正解チャイム、ブブー、カウントダウン音）
  - 結果画面でのまちがえた問題のふくしゅう＆豆知識解説

---

## 📱 スマートフォンでの遊び方（Wi-Fiローカルテスト）

パソコンと同じWi-Fiにスマホをつないだ状態で、パソコン側で開発サーバーを立ち上げます:
```bash
npm run dev -- --host
```
表示されたローカルIPアドレス（例: `http://172.16.80.67:5173`）をスマホのブラウザ（SafariやChrome）で開くだけで遊べます！

## 🚀 GitHub Pages への公開手順（完全無料）

1. **GitHubに新しいリポジトリを作成**（例: `FlagQuiz`）
2. **コードをプッシュ**:
   ```bash
   git init
   git add .
   git commit -m "feat: 初回リリース"
   git branch -M main
   git remote add origin https://github.com/あなたのユーザー名/FlagQuiz.git
   git push -u origin main
   ```
3. **GitHubのリポジトリ設定**:
   - リポジトリの **Settings** > **Pages** を開く
   - **Build and deployment** の **Source** を **「GitHub Actions」** に変更する
4. プッシュすると自動的にビルド＆公開が完了し、公開URL（`https://あなたのユーザー名.github.io/FlagQuiz/`）が発行されます！
5. スマホのSafari/ChromeでそのURLを開き、**「ホーム画面に追加」** を押せば、アプリアイコンからいつでも全画面で遊べます！
