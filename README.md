# 🚩 こっきクイズ (FlagQuiz)

子どもがスマートフォンで楽しく遊べる国旗＆地理クイズWebアプリです。
国旗だけでなく、国旗の由来・豆知識、国土のシルエット、周辺国と一緒に出題される地図クイズなど、多彩な切り口で世界中の国を楽しく学べます。

---

## 🌟 主な機能・あそびかた

### 1. 6つのプレイモード
- 🎲 **ランダム**: すべての出題形式がバランスよくミックスで登場！
- 🚩 **国旗あて**: 国旗画像を見て4つの国名から選択。
- 🔤 **なまえあて**: 国名を見て4つの国旗画像から正解を選択。
- 📖 **ゆらいクイズ**:
  - 「中央の星は何個？」「なぜこの色？」「なぜ四角形じゃないの？」など、国旗検定レベルの面白いトリビアを出題（120問以上収録）。
  - 解答後には「まめちしき解説」が表示され、じっくり読めるよう自動送り時間を長めに確保。さらに「つぎへ進む」ボタンで自分のペースで進められます。
- 🗺️ **かたちあて（シルエットクイズ）**:
  - 国の輪郭（シルエット）を見て国名を答える、または国名から形を選ぶクイズ。
- 📍 **ばしょ・ちず（周辺国マップクイズ）**:
  - 周辺の国々が薄いグレーで表示され、対象の国が鮮やかなオレンジ色でハイライト！
  - 「周りにどんな国があるか」「どの海に面しているか」という位置関係から楽しく推理できます。

### 2. 世界の全独立国を完全網羅（全199カ国・地域）
- 国連加盟国193カ国 ＋ バチカン、パレスチナ、コソボ、台湾、クック諸島、ニウエなど、世界中のすべての国を収録。
- 全地域（全世界、アジア、ヨーロッパ、アフリカ、北・中央アメリカ、南アメリカ、オセアニア）のエリア絞り込みに対応。

### 3. スピード加点 ＆ 週間ランキング
- **スピードボーナス**: 正解時の基本点（1,000点）に加え、早く答えるほど高得点（残り時間に応じて最大+1,000点）！
- **プレイヤー名登録**: ひらがなやニックネームを入力してプレイ可能（自動記憶）。
- **週間（ウィークリー）ランキング**: 端末内に今週（月〜日）のハイスコアランキングを自動記録。家族や友達と競い合えます。

### 4. 子ども向けUI & 復習コーナー
- **ふりがな（ルビ）表示**: すべての国名・質問文にふりがなを標準装備（設定でON/OFF可能）。
- **ふくしゅうコーナー**: クイズ終了後に、間違えた国の「国旗」と「地図・かたち」をダブルで並べて表示。由来の豆知識と一緒に視覚的・直感的に学べます。
- **効果音**: Web Audio APIによる軽快な正解・不正解・カウントダウン音（ON/OFF可能）。
- **PWA対応**: スマートフォンの「ホーム画面に追加」でアドレスバーのない全画面アプリとして起動可能。

## 🎮 ゲーム設定項目
- **もんだいすう**: 5問 / 10問 / 20問 / 50問 / **100問**
- **制限時間**: **3秒（超スピード）** / 5秒 / 10秒 / 15秒 / なし（じっくり）
- **ちいきフィルター**: 全世界 / アジア / ヨーロッパ / アフリカ / 北・中央アメリカ / 南アメリカ / オセアニア

## 📱 スマートフォンでの遊び方

### 公開URLから遊ぶ（おすすめ）
👉 **https://Shin-ichiroh.github.io/FlagQuiz/**

#### アプリとしてホーム画面に追加する方法:
- **iPhone (Safari)**: 画面下の共有ボタン（四角から上矢印） ＞ **「ホーム画面に追加」**
- **Android (Chrome)**: 右上のメニュー（3点リーダー） ＞ **「ホーム画面に追加」** または **「アプリをインストール」**

### Wi-Fi経由でローカルテストする場合
パソコンとスマホが同じWi-Fiに接続されている状態で、以下のコマンドを実行:
```bash
npm run dev -- --host
```
ターミナルに表示されるローカルIPアドレス（例: `http://172.16.80.67:5173`）をスマホのブラウザで開きます。

## 🛠️ 開発・技術スタック
- **フロントエンド**: React 19 + TypeScript + Vite
- **スタイリング**: Tailwind CSS v4 + Lucide Icons
- **地図・データ**:
  - 国旗画像: [Flagcdn](https://flagcdn.com/)
  - 国土シルエット: [mapsicon](https://github.com/djaiss/mapsicon)
  - 周辺国マップ: GeoJSON ベクターデータ + SVG動的投影レンダリング
- **ホスティング**: GitHub Pages (GitHub Actions自動デプロイ)
