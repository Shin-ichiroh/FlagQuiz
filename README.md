# 🚩 こっきクイズ (FlagQuiz)

子どもがスマートフォンで楽しく遊べる国旗＆地理クイズWebアプリです。
国旗だけでなく、国旗の由来・豆知識、国土のシルエット、周辺国と一緒に出題される地図クイズなど、多彩な切り口で世界中の国を楽しく学べます。

---

## 🌟 主な機能・あそびかた

### 1. 7つのプレイモード
- 🎲 **ランダム**: すべての出題形式がバランスよくミックスで登場！
- 🚩 **国旗あて**: 国旗画像を見て4つの国名から選択。
- 🔤 **なまえあて**: 国名を見て4つの国旗画像から正解を選択。
- 📖 **ゆらいクイズ**:
  - 「中央の星は何個？」「なぜこの色？」「なぜ四角形じゃないの？」など、国旗検定レベルの面白いトリビアを出題（120問以上収録）。
  - 解答後には「まめちしき解説」が表示され、じっくり読めるよう自動送り時間を長めに確保。さらに「つぎへ進む」ボタンで自分のペースで進められます。
- 🗺️ **かたちあて（シルエットクイズ）**:
  - 国の輪郭（シルエット）を見て国名を答える、または国名から形を選ぶクイズ。
- 📍 **ばしょ・ちず（周辺国マップクイズ）**:
  - 周辺の国々が薄いグレーで表示され、対象の国が鮮やかなオレンジ色でハイライト！
  - 「周りにどんな国があるか」「どの海に面しているか」という位置関係から楽しく推理できます。
- ⚔️ **国くらべ（面積・人口の比較クイズ）**:
  - 2つの国のカード（国旗・国名つき）を並べて「面積が広いのはどっち？」「人口（人の数）が多いのはどっち？」を比べるクイズ！
  - 解答後には具体的な面積（km²）や人口の数値、豆知識が表示されます。

### 2. 🧩 たのしい知育・パズルコーナー（新登場！）
トップ画面の専用コーナーから、クイズとは一味違ったインタラクティブな知育ゲームが楽しめます。

- 🧩 **こっきパズル（9ピース／4ピースパズル）**:
  - 全世界の国旗をバラバラにシャッフル！ピースを2つタップして位置を入れ替え、国旗を完成させるパズルです。
  - 「3×3（9ピース・ふつう）」と「2×2（4ピース・かんたん）」の難易度切り替えに対応。
  - タイル番号ヒントやおてほんミニプレビュー機能、完成時の紙吹雪演出＆音声読み上げつき。
- ⭐ **マークパズル（国旗づくりパズル）**:
  - 国旗のベースに、星・三日月・太陽・天球儀・十字などのシンボルやマークを正しい位置に配置する知育パズル。
  - 日本（日の丸）、アメリカ（50星のカントン）、ブラジル（ひし形と天球儀）、トルコ（三日月と星）、スイス（正方形スイスクロス）、韓国（太極円と四卦）、アルゼンチン（五月の太陽）など多彩なステージを収録。
  - 各国のマークの歴史や由来が学べる豆知識解説＆音声読み上げつき。
- 🎨 **こっきぬりえ（国旗塗り絵）**:
  - 白黒の枠線に、えのぐパレットから好きな色を選んでタップして塗るインタラクティブ塗り絵！
  - おてほんを見ながら正しい色を塗って「できた！」ボタンで答え合わせ。
  - 塗った国旗は「画像保存」ボタンでPNG画像としてスマートフォンやPCに保存・ダウンロード可能！

### 3. 世界の全独立国を完全網羅（全199カ国・地域）
- 国連加盟国193カ国 ＋ バチカン、パレスチナ、コソボ、台湾、クック諸島、ニウエなど、世界中のすべての国を収録。
- 全地域（全世界、アジア、ヨーロッパ、アフリカ、北・中央アメリカ、南アメリカ、オセアニア）のエリア絞り込みに対応。
- 全199カ国の「面積」「人口」「現地のあいさつ言葉」のデータを収録！

### 4. スピード加点 ＆ 週間ランキング
- **スピードボーナス**: 正解時の基本点（1,000点）に加え、早く答えるほど高得点（残り時間に応じて最大+1,000点）！
- **プレイヤー名登録**: ひらがなやニックネームを入力してプレイ可能（自動記憶）。
- **週間（ウィークリー）ランキング**: 端末内に今週（月〜日）のハイスコアランキングを自動記録。家族や友達と競い合えます。

### 5. 子ども向けUI・音声読み上げ & 復習コーナー
- **🗣️ 音声読み上げ（Web Speech API）**:
  - 問題文や正解の国名を自然な日本語音声で読み上げ！まだ漢字や長い文字を読むのが難しいお子様でも耳で聞いて楽しめます（設定画面やクイズ画面のボタンでいつでもON/OFF切り替え可能）。
  - 各国の現地のごあいさつ（例: 「オラ」「ジャンボ」「ボンジュール」など）も音声ボタンで聴くことができます。
- **ふりがな（ルビ）表示**: すべての国名・質問文にふりがなを標準装備（設定でON/OFF可能）。
- **ふくしゅうコーナー**: クイズ終了後に、間違えた国の「国旗」「地図・かたち」「現地のあいさつ」を並べて表示。スピーカーアイコンを押せばいつでも発音を聴くことができます。
- **効果音**: Web Audio APIによる軽快な正解・不正解・カウントダウン音（ON/OFF可能）。
- **PWA対応**: スマートフォンの「ホーム画面に追加」でアドレスバーのない全画面アプリとして起動可能。

## 📱 スマートフォンでの遊び方

### 公開URLから遊ぶ（おすすめ）
👉 **https://Shin-ichiroh.github.io/FlagQuiz/**

#### アプリとしてホーム画面に追加する方法:
- **iPhone (Safari)**: 画面下の共有ボタン（四角から上矢印） ＞ **「ホーム画面に追加」**
- **Android (Chrome)**: 右上のメニュー（3点リーダー） ＞ **「ホーム画面に追加」** または **「アプリをインストール」**

### Wi-Fi経由でローカルテストする場合
パソコンとスマホが同じWi-Fiに接続されている状態で、以下のコマンドを実行:
```bash
npm run dev -- --host
```
ターミナルに表示されるローカルIPアドレス（例: `http://172.16.80.67:5173`）をスマホのブラウザで開きます。
